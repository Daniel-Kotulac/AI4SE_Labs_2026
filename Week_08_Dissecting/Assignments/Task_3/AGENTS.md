# Repository Guidelines

## Project

This repository contains weekly AI for Software Engineering course labs and assignments. Follow the instructions in the relevant week and task files; they are the source of truth for each deliverable.

## Working in the Repository

- Keep changes scoped to the task. Preserve existing student work and do not rewrite unrelated reports or assignment materials.
- Place new assignment outputs in the corresponding week/task directory and use any filename or format specified by the assignment.
- For written work, use clear Markdown and distinguish verified results from assumptions.
- Do not invent test results, screenshots, or tool capabilities. State when something could not be verified.

## Validation

- Check the relevant assignment instructions and review the final diff before finishing.
- Run tests or other checks only when the task or the affected code provides a relevant way to do so; this repository has no identified repository-wide test command.
